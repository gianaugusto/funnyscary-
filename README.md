# funnyscary-
👻 Suspense, sustos e curiosidades 

Página de links sociais do Scary Go Funny, feita em HTML e CSS e pronta para publicar no GitHub Pages.

## Publicar no GitHub Pages

1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
4. A página ficará disponível em `https://gianaugusto.github.io/funnyscary-/`.

Os links sociais, textos e metadados de busca estão em [index.html](./index.html).
